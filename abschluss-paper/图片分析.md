\subsection{ROI Refinement 模块有效性分析}
\label{subsec:roi_refinement_effectiveness_cn}

本节对提出的 ROI refinement 模块进行有效性分析，重点关注其对小物体类别的影响。该模块的核心动机是补偿粗粒度 decoder feature 中细粒度局部信息不足的问题，因此本文首先根据物体在图像中的空间占比筛选小物体类别。具体而言，对于每一个目标类别，统计该类别所有实例的 bounding box 面积与整张图像面积之间的平均比例，并按照该比例从小到大排序。根据该统计结果，数据集中最小的五个类别分别为 \textit{doorknob}、\textit{sandwich}、\textit{medicine}、\textit{light} 和 \textit{dish}。这些类别更容易受到特征下采样和空间细节丢失的影响，因此适合作为 ROI refinement 模块的重点分析对象。

图~\ref{fig:roi_recall_small_categories} 对比了原始 SAM3-based SpeaQ 模型与加入 ROI refinement 模块后的 Recall@50 表现。其中，``Original'' 表示未加入 ROI refinement 的 SAM3-based SpeaQ 模型，``ROI'' 表示启用本文提出的 ROI refinement 分支后的模型。结果显示，在所选取的五个小物体类别上，ROI refinement 均带来了提升或至少保持了原有性能。特别是对于 \textit{medicine} 和 \textit{light} 两个类别，Recall@50 分别从 1.8 提升到 18.4，以及从 9.6 提升到 40.4。\textit{dish} 类别也从 31.1 提升到 40.0，\textit{sandwich} 从 23.3 提升到 24.8。相比之下，\textit{doorknob} 类别保持在 17.9，说明该类别由于尺寸极小、视觉线索有限，即使引入高分辨率局部特征后仍然较难识别。

这些结果表明，ROI refinement 模块对于原始 decoder representation 难以保留充分视觉信息的小物体类别具有明显帮助。虽然将 ResNet-101 backbone 替换为 SAM3 能够提升模型整体的视觉表征能力，但直接使用 SAM3-based SpeaQ baseline 时，小物体类别的识别效果仍然存在明显不足。这说明更强的全局视觉特征本身并不足以完全解决小物体的细粒度分类问题。通过从原生高分辨率特征图中提取局部 RoI 特征，ROI refinement 分支为这些类别提供了额外的类别判别信息。

为了进一步分析 recall 提升是否与分类准确性相关，本文统计了由于分类错误导致的检测失败数量。在目标检测评估中，一个预测框只有在位置匹配和类别预测同时正确时才会被判定为 true positive。因此，对于那些与 ground-truth 具有较高空间重合度但类别预测错误的预测框，其失败原因主要来自分类错误，而不是定位错误。图~\ref{fig:roi_cls_wrong} 展示了启用 ROI refinement 前后这类分类错误数量的变化。

结果显示，在大多数选取的小物体类别上，ROI refinement 都减少了分类错误数量。例如，\textit{sandwich} 的分类错误数量从 166 降低到 130，\textit{medicine} 从 69 降低到 36，\textit{light} 从 12 降低到 4，\textit{dish} 从 277 降低到 169。在全部 31 个目标类别上，分类错误总数也从 3975 降低到 3577。这一结果支持了如下判断：ROI refinement 主要通过修正已经具有较好定位结果的预测框类别，从而提升最终检测质量。唯一例外是 \textit{doorknob} 类别，其错误数量从 0 变为 1。考虑到该类别本身尺寸极小且视觉证据非常有限，这一轻微波动并不改变整体趋势。

除了最终检测统计结果外，本文还在训练过程中监控了 ROI refinement 分支中 gate 的平均值，如图~\ref{fig:roi_gate_mean} 所示。gate 初始化为 0.5，表示训练初始阶段原始 decoder feature 与高分辨率 RoI feature 具有相同的贡献权重。在优化过程中，平滑后的 gate value 首先从初始化值快速下降，随后逐渐回升，并最终稳定在约 0.32 附近。训练结束时，raw gate value 为 0.3568，smoothed gate value 为 0.3186。该现象说明，从整体平均趋势来看，模型仍然更依赖原始 decoder representation，但高分辨率 ROI feature 仍然提供了有意义的补充信息。

一种合理解释是，数据集中并非所有目标都是极小物体。对于许多中等或较大的目标，原始 decoder representation 已经包含了较充分的语义信息，足以支持类别判断。此外，由于 Transformer decoder 中 self-attention 和 cross-attention 的作用，原始 query representation 并不是纯局部特征。它可能已经融合了邻近 query、全局图像特征以及 relation-aware interaction 中的上下文信息。因此，对于许多常规尺度目标，原始 decoder feature 仍然是更稳定且信息更丰富的表征来源。相比之下，ROI refinement 分支主要在原始表征缺乏足够细粒度证据时发挥作用，尤其适用于小物体或视觉上容易混淆的类别。

这一解释也可以从图~\ref{fig:roi_gate_by_size} 中的尺寸分组 gate 统计得到进一步支持。在该分析中，本文根据目标 bounding box 面积占整张图像面积的比例，将匹配到的 object queries 分为小物体组和较大物体组，并以 0.02 作为阈值。模型收敛后，小物体 query 的 gate value 略高于较大物体 query。这说明模型在处理小物体时会自适应地给予 ROI refinement 分支更高权重，这与该模块的设计动机一致。

总体而言，ROI refinement 模块通过引入高分辨率局部特征，改善了小物体类别的分类与检出效果。Recall 对比结果说明该模块能够提升最终检测质量；分类错误统计表明其能够减少由类别预测错误导致的检测失败；gate 动态分析则进一步说明，模型并不是完全替代原始 decoder representation，而是将 ROI feature 作为互补信息源进行选择性利用。


为了进一步验证 ROI refinement 模块的有效性是否依赖于 SAM3 backbone，本文额外在 ResNet-101 作为视觉主干网络的条件下进行了对照实验。结果如表~\ref{tab:resnet_roi_small_object_recall_cn} 所示。相比于原始 ResNet-101 baseline，加入 ROI refinement 后，五个选定的小物体类别在 Recall@50 上均获得了提升。

其中，\textit{medicine} 和 \textit{light} 两个类别的提升最为明显，Recall@50 分别从 3.067 提升到 15.951，以及从 22.340 提升到 40.426。\textit{sandwich} 类别也从 17.444 提升到 25.865。\textit{doorknob} 的提升幅度相对较小，但仍然从 31.457 提升到 34.106。\textit{dish} 类别只呈现轻微提升，这可能是因为该类别在原始 ResNet-101 baseline 中已经具有相对较高的 recall，因此进一步提升空间较小。

该实验表明，ROI refinement 的收益并不局限于 SAM3-based model。相反，该模块通过对预测目标区域进行局部区域级特征提取，为小物体类别提供了更加细粒度的分类信息，因此可以作为一种较通用的小物体识别增强机制。由于该模块位于 decoder 之后，不需要大幅修改 backbone 或主 Transformer 结构，因此具有较好的可插拔性和模型兼容性。

总体而言，ResNet-101 上的实验结果补充了前文基于 SAM3 backbone 的分析。SAM3 实验说明 ROI refinement 在更强视觉主干下仍然有效，而 ResNet-101 实验则进一步说明该模块同样适用于传统卷积主干。因此，ROI refinement 带来的性能提升更应被理解为区域级细化设计本身的作用，而不是依赖于某一个特定 backbone 的偶然结果。
