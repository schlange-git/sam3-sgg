## 3.X 面向长尾与尺度差异的对象分类头拆分方法

### 3.X.1 研究动机

在 Action Genome 场景图生成任务中，目标对象识别不仅决定对象检测结果本身，还会进一步影响关系三元组 (subject, predicate, object) 的构造质量。由于关系推理建立在对象类别、对象框及其配对关系之上，一旦对象类别预测出现偏差，后续三元组匹配通常会直接失败，从而导致关系评估指标同步下降。因此，对象分类分支的鲁棒性对于场景图生成任务具有基础性作用。

然而，Action Genome 的对象分布具有显著的长尾特性，不同类别在样本频次、目标尺度和上下文依赖程度上均存在较大差异。一方面，`person`、`table`、`floor`、`chair` 等高频类别在训练过程中能够获得充分监督，因而通常表现出较高的召回率；另一方面，`medicine`、`doorknob`、`light`、`sandwich`、`groceries` 等低频类别样本稀少，且多数目标面积较小，极易受到背景噪声和尺度变化的影响，导致识别性能明显不足。与此同时，一些类别在视觉外观及关系语义上具有较强相似性，例如 `sandwich` 与 `food`、`door` 与 `doorway`、`book` 与 `papernotebook` 等，这使得单一共享分类头在统一特征空间中难以学习到清晰、可分的判别边界。

现有研究针对视觉关系检测和场景图生成中的长尾问题，通常采用数据重采样、损失重加权或类别特定分类器等方式进行缓解。但这类方法本质上仍是在有限模型容量下重新分配训练权重，往往需要在高频类与低频类之间进行折中。SpeaQ 的研究表明，相较于单纯重加权，更有效的途径是通过 specialization 提升模型容量利用率，使不同 query 学习不同子任务，从而缓解长尾分布带来的训练冲突。受此启发，本文将“specialization”的思想由 query 层进一步扩展至对象分类层，提出一种面向长尾类别、尺度差异和语义混淆的对象分类头拆分方法。该方法在保留全局共享分类能力的同时，引入面向不同语义簇和不同尺度的专家分类分支，以提高尾部类别和易混淆类别的判别能力。

此外，HRT 的研究指出，在复杂场景图生成中，同一对象可能在多个重叠 triplet 中扮演不同角色，若缺乏与 triplet 语义对齐的特征表示，component-level 的对象和关系表示容易发生混淆。该现象进一步说明，单一对象分类头难以同时适应所有语义上下文。因此，从对象分类层面引入更具结构化的多头机制，不仅有助于对象识别本身，也为后续关系推理提供更稳定的语义基础。

### 3.X.2 方法总体框架

为解决上述问题，本文设计了一种“共享头 + 专家头 + 层级监督”的对象分类框架。该框架并不直接替换原有分类头，而是在原始全局分类分支的基础上，额外引入混淆簇粗分类分支、簇内细分类分支以及尺度专家分支。整体上，模型仍输出原始 Action Genome 对象类别，不改变现有 benchmark 的标签定义与评测协议。

具体而言，设解码器输出的第 i 个 object query 特征为 f_i。传统单头分类方式可表示为：

y_i^global = W_g f_i + b_g

其中，y_i^global 为在全部对象类别空间上的分类 logits。为增强模型对语义相近类别的区分能力，本文进一步引入粗粒度语义簇分类头：

y_i^coarse = W_c f_i + b_c

其中，粗分类头输出对象所属语义簇，例如 food-like、door-like、paper-like 等。随后，在每个语义簇内部构建独立的细分类专家头。若 object query 被划分到第 k 个语义簇，则其簇内细分类结果为：

y_i^{fine,k} = W_k f_i + b_k

其中，W_k 和 b_k 表示第 k 个语义簇对应的专家分类器参数。细分类专家头仅在簇内类别集合上进行判别，从而降低全类别统一分类时的边界学习难度。

为了进一步适配不同尺度目标的识别需求，本文在上述语义层级划分的基础上，引入尺度路由与尺度专家头。根据目标框面积占原图面积的比例，将对象划分为 tiny、small 和 normal 三个尺度桶。模型首先通过一个轻量路由器预测 object query 所属尺度，再使用对应的尺度专家头进行补充判别。设尺度路由结果为 s_i，则尺度专家输出可写为：

y_i^{size} = W_{s_i} f_i + b_{s_i}

最终，对象分类 logits 由全局头与专家头共同构成：

y_i^{final} = y_i^{global} + λ_1 · Proj(y_i^{fine}) + λ_2 · Proj(y_i^{size})

其中，Proj(·) 表示将簇内分类结果或尺度专家结果映射回完整类别空间，λ_1 和 λ_2 为融合权重。通过这一设计，模型能够在保留全局一致语义空间的同时，针对尾部类别、尺度敏感类别及高混淆类别形成更精细的局部决策边界。

### 3.X.3 混淆簇构建策略

对象分类头拆分的关键在于如何构建语义簇。若仅凭人工经验划分类别，虽然实现简单，但容易受主观因素影响，且无法充分反映实际训练中的混淆模式。为此，本文采用“数据统计 + 人工修正”的混合策略构建语义簇。

首先，在验证集上统计对象类别的混淆矩阵。设类别 i 被误分为类别 j 的条件概率为 P(i→j)，则定义对称混淆强度为：

S_conf(i,j) = 0.5 · ( P(i→j) + P(j→i) )

其次，考虑到对象类别不仅在视觉上可能相似，在关系语义上也可能具有相近分布，因此进一步统计各类别作为 subject 或 object 时的谓词分布，构建关系语义表示 r_i。基于此，可通过余弦相似度衡量类别 i 与类别 j 的关系语义相近程度：

S_rel(i,j) = cosine(r_i, r_j)

最终，综合视觉混淆与关系语义相似性，定义类别对之间的聚合相似度：

S(i,j) = α · S_conf(i,j) + β · S_rel(i,j)

基于该相似度矩阵，可采用层次聚类或谱聚类获得候选语义簇，并结合具体类别语义进行人工修正。根据当前 AG 数据特征，本文优先关注以下若干高混淆类别簇：

1. food-like：`food`、`sandwich`、`medicine`
2. door-like：`door`、`doorknob`、`doorway`
3. paper-like：`book`、`papernotebook`
4. carry-like：`bag`、`groceries`
5. display-like：`mirror`、`picture`、`window`、`television`
6. container-like：`cupglassbottle`、`dish`

这种“先粗分类、后簇内细分类”的方式能够避免近义类别之间在训练早期即被视为完全错误，从而保留 coarse-level 的有效监督信号，减轻尾部类别因误分类而难以学习的问题。

### 3.X.4 损失函数设计

为使全局分类能力与专家分类能力共同发挥作用，本文采用多任务联合监督方式优化对象分类分支。整体对象分类损失由四部分构成：全局分类损失、粗粒度簇分类损失、簇内细分类损失以及尺度路由损失。

首先，全局分类损失用于维持模型在完整类别空间上的基础识别能力：

L_global = CE(y^{global}, c)

其中，c 为原始对象类别标签。

其次，粗粒度簇分类损失定义为：

L_coarse = CE(y^{coarse}, g(c))

其中，g(c) 表示类别 c 所对应的语义簇标签。

对于属于某个语义簇的样本，再施加簇内细分类损失：

L_fine = CE(y^{fine,k}, h_k(c))

其中，h_k(c) 表示类别 c 在第 k 个语义簇内部的局部标签。对于不属于任何混淆簇的类别，可不计算该项损失。

在尺度层面，若匹配到的真实框面积属于尺度桶 s，则尺度路由损失为：

L_size = CE(y^{size-route}, s)

综上，总对象分类损失写为：

L_obj = λ_g L_global + λ_c L_coarse + λ_f L_fine + λ_s L_size

其中，λ_g、λ_c、λ_f 和 λ_s 分别控制各损失项的贡献。实验中，通常令 λ_g 保持最大，以避免专家头对高频稳定类别造成过度干扰，而将 λ_c、λ_f 与 λ_s 作为辅助监督项逐步引入。

若进一步考虑到近义类别之间边界过近的问题，还可以增加混淆对 margin loss，对已知高混淆类别对施加更强的特征分离约束。例如，对于 `sandwich` 与 `food`、`door` 与 `doorway` 等类别对，可在分类特征空间中主动拉大其边界间隔，以提升细粒度判别能力。

### 3.X.5 与关系分支的协同建模

在场景图生成任务中，对象识别与关系推理并非相互独立。当前框架中，模型在前向过程中同时输出对象级别的 `pred_logits` 与 `pred_boxes`，以及关系级别的 `relation_logits` 和 `rel_pair_idx`，后者用于指示每条关系预测所对应的 subject-object 对。评估阶段再将其组织为 triplet 结构进行匹配。因此，若对象分类头能够提供更稳定、更有区分性的对象语义表示，则理论上也能改善关系分支的推理质量。

基于这一考虑，本文进一步将对象专家头学习到的 coarse 语义与尺度语义作为 side information 注入 relation 分支。具体来说，对于一条候选关系边 (u, v)，分别提取其 subject 和 object 的 coarse cluster embedding 与 size embedding，并与原有 relation query 特征进行拼接或线性融合，以增强关系分支对对象语义上下文的利用能力。通过这种方式，relation head 不再仅依赖局部视觉特征和基础对象类别信息，而是能够获得更结构化的对象语义提示，从而在 `food/sandwich`、`door/doorknob/doorway` 等高混淆语境中形成更稳定的三元组判别。

这种设计也与 HRT 所强调的“对象特征与 triplet 语义对齐”思想相一致。即，在复杂场景中，同一对象可能在多个 triplet 中扮演不同角色，若 object-level representation 能够在 coarse/fine 语义层面得到更充分的 disentangle，则关系分支更容易建立正确的 subject-predicate-object 对应关系。

### 3.X.6 实验设计与评价指标

为了验证所提方法的有效性，本文将采用分阶段消融实验。第一阶段仅引入混淆簇粗分类头与簇内细分类头，以验证“层级分类”本身是否能改善长尾类别和易混淆类别性能；第二阶段进一步加入尺度路由与尺度专家头，验证多尺度专家机制对 tiny/small 目标的促进作用；第三阶段将对象语义簇信息与尺度信息注入 relation 分支，以评估对象分类改进是否能够传导至 triplet 指标；最后，可选地加入 margin loss 或 triplet-style alignment loss，以进一步提升多角色对象和复杂关系场景中的判别能力。

评价指标方面，除总体 object recall 外，本文还将重点分析以下几个维度：

1. 各对象类别的 per-class recall；
2. 长尾类别平均 recall；
3. 不同尺度组（tiny、small、normal）的平均 recall；
4. 高混淆类别对的误分类率；
5. triplet 的 R@20、R@50、R@100；
6. triplet 的 mR@20、mR@50、mR@100。

通过上述多维评估，可以更全面地分析对象分类头拆分究竟改善了哪些类别、哪些场景以及哪些错误模式，而非仅依赖单一总体指标作出结论。

### 3.X.7 方法优势与预期贡献

与传统单一分类头相比，本文方法具有以下优势。

第一，本文并不简单依赖数据重采样或损失重加权，而是通过显式引入专家分类机制提升模型对不同类别子空间的表达能力，从而缓解统一分类器在长尾分布下的学习冲突。

第二，本文通过粗到细的层级分类结构保留了近义类别的 coarse-level 正监督，减少了“预测相近类别即完全负样本”的训练浪费问题，尤其适用于 AG 中存在明显语义重叠的类别对。

第三，本文通过尺度路由与尺度专家头提升模型对 tiny/small 对象的适应能力，使小目标不再被迫与大目标共享完全一致的分类边界和特征需求。

第四，本文将对象分类的结构化语义进一步传递至关系分支，实现 object recognition 与 relation reasoning 的协同优化，为场景图生成任务提供更稳健的三元组构造基础。

综上，本文提出的对象分类头拆分方法本质上是将 specialization 思想由 query 学习扩展到 object classification learning，并结合尺度自适应与语义簇建模，使其更适应 Action Genome 中长尾、多尺度、强语义混淆的对象分布特征。预计该方法不仅能够改善尾部类别和小目标类别的识别性能，也有望进一步提升 triplet recall 与 mean recall，为基于 Transformer 的场景图生成研究提供一种可解释、可扩展的改进方向。
