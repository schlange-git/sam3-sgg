# 分类头拆分调试报告

## 1. 目标

本次调试围绕以下改动进行自动验证：

1. `OBJ_SPLIT` 配置接入与启动期校验；
2. `regular + small_shared + fine + bg` 多头分类组装为统一 `pred_logits`；
3. 2x 上采样分支路径（small/fine 可选）；
4. 温度缩放校准；
5. criterion 中 split auxiliary loss（`loss_reg_aux/loss_small_aux/loss_fine_aux`）；
6. 评测侧 head-source 统计输出。

---

## 3. 关键修复点

1. **配置校验**：新增 `validate_obj_split_config(cfg, num_classes)`，校验互斥、覆盖完整、ID 范围、fine 配置长度一致性。
2. **多头组装**：`SplitObjectClassifier` 将各分支 logits 组装为统一全类别 logits。
3. **分支增强**：small/fine 支持分类前 2x 双线性上采样（轻量 token->2D->pool 路径）。
4. **校准**：支持 per-head 温度缩放。
5. **辅助损失**：criterion 新增 split auxiliary loss 计算与训练汇总。
6. **评测分析**：新增 triplet 中 subject/object head 来源计数统计。

---

## 4. 核心代码修改清单

### 4.1 配置与校验

- `configs/defaults.py`
  - 新增 `MODEL.OBJ_SPLIT.*` 配置项：
    - `ENABLED`
    - `REGULAR_CLASSES`
    - `SMALL_SHARED_CLASSES`
    - `FINE_GROUPS`
    - `FINE_GROUP_NAMES`
    - `FINE_GROUPS_USE_UPSAMPLE`
    - `SMALL_SHARED_USE_UPSAMPLE`
    - `USE_TEMP_SCALING`
    - `AUX_LOSS_WEIGHT_REG/SMALL/FINE`
- `configs/speaq_actiongenome_minimal.yaml`
  - 增加 `OBJ_SPLIT` 配置块（默认关闭，支持实验分阶段开启）。
- `modeling/meta_arch/detr.py`
  - 新增 `validate_obj_split_config(cfg, num_classes)`；
  - 在 `Detr.__init__` 中启动时执行配置校验（非法配置直接报错停止）。

### 4.2 模型结构与前向输出

- `modeling/transformer/transformer.py`
  - 新增 `SplitObjectClassifier`：
    - 分支头：`regular_head / small_shared_head / fine_head_dict / bg_head`
    - 2x 上采样：small/fine 分支可选
    - 温度缩放：`tau_regular/tau_small/tau_fine`
    - 全类别组装：输出统一 `full_logits`
    - 头来源追踪：`head_source_idx`
    - 调试原始输出：`raw_split_logits`
  - `IterativeRelationTransformer` 接入 split-head 路径：
    - `relation_subject_logits` / `relation_object_logits` 使用统一组装 logits；
    - 透传 `obj_split_*_head_source_idx` 与 `raw_split_logits_*`。
- `modeling/transformer/detr.py`
  - 将上述 split 输出透传到顶层 `out`；
  - 支持 aux 层 split 输出（`aux_outputs_obj_split`）。

### 4.3 损失函数改造

- `modeling/transformer/criterion.py`
  - 新增 split 配置解析字段：
    - `obj_split_enabled`
    - `obj_split_regular_classes`
    - `obj_split_small_classes`
    - `obj_split_fine_groups`
    - `obj_split_fine_names`
  - 新增函数：
    - `_compute_obj_split_aux_for_role(...)`
    - `get_obj_split_aux_losses(...)`
  - 在主层与 aux 层损失聚合中接入：
    - `loss_reg_aux`
    - `loss_small_aux`
    - `loss_fine_aux`
- `modeling/meta_arch/detr.py`
  - `weight_dict` 挂接 split aux 权重（由 `MODEL.OBJ_SPLIT.AUX_LOSS_WEIGHT_*` 控制）；
  - `build_criterion(...)` 传入 split 配置。

### 4.4 推理与评测统计

- `modeling/meta_arch/detr.py`
  - 在推理阶段将 `obj_split_sub_head_source/obj_split_obj_head_source` 挂到结果对象；
  - 结果回传中同步这两个字段，供 evaluator 使用。
- `evaluation/sg_evaluation.py`
  - `process(...)` 中读取并保存 head-source 字段；
  - `evaluate(...)` 增加 `obj_split_triplet_head_source` 汇总输出；
  - 新增 `_summarize_obj_split_head_source(...)`：
    - `subject_head_source_count`
    - `object_head_source_count`
    - `pair_head_source_count`

## 5. 已知限制与后续建议

1. 当前 split auxiliary loss 主要作用于最终层；如需更强约束，可扩展到每层并引入 layer-wise 权重退火。
2. 2x 上采样目前是轻量可复现实现；后续可替换为显式局部 2D patch 特征适配器。
3. head-source 统计已接入 evaluator 输出，但尚未在默认日志模板中绘图展示，建议后续补可视化脚本。
