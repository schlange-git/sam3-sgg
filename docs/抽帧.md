+# Action Genome 时序抽帧增强策略说明（论文风格）
+
+## 1. 背景与问题定义
+
+在 Action Genome 场景图生成任务中，原始抽帧策略通常存在两个极端：
+
+1. **仅保留标注关键帧（annotation-only）**：样本过稀，时序建模难以学习连续动态，容易导致时序分支欠拟合。
+2. **保留视频全帧（full frames）**：样本冗余严重，I/O 与存储压力显著增加，训练吞吐下降。
+
+为平衡“时序信息密度”与“计算代价”，本次修改引入一种轻量级的**间隔插值抽帧**策略：  
+在每一对相邻关键帧之间，额外均匀采样固定数量的中间帧（默认 2 帧）。
+
+---
+
+## 2. 方法描述
+
+设同一视频中按时间排序后的关键帧索引序列为：
+
+\[
+\mathcal{K}=\{k_1, k_2, \dots, k_n\},\quad k_i < k_{i+1}
+\]
+
+对于每个区间 \((k_i, k_{i+1})\)，设区间内部可用帧数为：
+
+\[
+\Delta_i = k_{i+1} - k_i - 1
+\]
+
+给定每区间的目标增补帧数 \(m\)（默认 \(m=2\)），实际采样数为：
+
+\[
+s_i = \min(m, \Delta_i)
+\]
+
+第 \(j\) 个增补帧（\(j \in [1, s_i]\)）的位置采用均匀分布近似：
+
+\[
+\hat{k}_{i,j} = k_i + \operatorname{round}\left(\frac{j\cdot (k_{i+1}-k_i)}{s_i+1}\right)
+\]
+
+并约束 \(\hat{k}_{i,j}\in(k_i, k_{i+1})\)，最终保留集合为：
+
+\[
+\mathcal{F} = \mathcal{K} \cup \{\hat{k}_{i,j}\}
+\]
+
+该策略在不引入复杂插值模型的前提下，提升关键帧间时序可观测性。
+

+## 3. 工程实现
+
+### 3.1 核心修改文件
+
+- `data/ActionGenome/tools/dump_frames.py`
+- `prepare_actiongenome_frames.sh`
+
+### 3.2 关键代码块
+
+在 `dump_frames.py` 中新增关键函数 `_augment_frames_between_keyframes(...)`，并在非 `--all_frames` 模式下调用：
+
+```python
+def _augment_frames_between_keyframes(key_frames, extra_frames_per_interval):
+    if extra_frames_per_interval <= 0:
+        return set(key_frames)
+
+    numeric_key_frames = []
+    for frame in set(key_frames):
+        stem, ext = os.path.splitext(frame)
+        if ext.lower() != ".png":
+            continue
+        if not stem.isdigit():
+            continue
+        numeric_key_frames.append((int(stem), len(stem)))
+
+    if len(numeric_key_frames) < 2:
+        return set(key_frames)
+
+    numeric_key_frames.sort(key=lambda x: x[0])
+    keep_frames = set(key_frames)
+
+    for (start_idx, width), (end_idx, _) in zip(numeric_key_frames[:-1], numeric_key_frames[1:]):
+        interior_count = end_idx - start_idx - 1
+        if interior_count <= 0:
+            continue
+
+        sample_count = min(extra_frames_per_interval, interior_count)
+        for i in range(1, sample_count + 1):
+            sampled_idx = start_idx + round(i * (end_idx - start_idx) / (sample_count + 1))
+            if start_idx < sampled_idx < end_idx:
+                keep_frames.add(f"{sampled_idx:0{width}d}.png")
+
+    return keep_frames
+```
+
+并新增 CLI 参数：
+
+```python
+parser.add_argument(
+    "--extra_frames_per_interval",
+    type=int,
+    default=0,
+    help=(
+        "When not using --all_frames, add this many uniformly sampled frames between every two adjacent "
+        "annotated key frames. Set to 0 to keep only annotated key frames."
+    ),
+)
+```
+
+Shell 入口脚本中默认设置：
+
+```bash
+EXTRA_FRAMES_PER_INTERVAL="${EXTRA_FRAMES_PER_INTERVAL:-2}"
+```
+
+并将该参数透传至 Python 抽帧程序。

+## 4. 复杂度与资源开销分析
+
+设某视频关键帧个数为 \(n\)，区间增补上限为 \(m\)。
+
+- **时间复杂度（筛选阶段）**：\(O(n \log n + n\cdot m)\)（排序主导，且 \(m\) 为小常数时近似 \(O(n\log n)\)）。
+- **空间复杂度**：\(O(n + n\cdot m)\)（保存保留帧集合）。
+- **I/O 开销变化**：相较 annotation-only 增加；相较 full-frames 大幅降低，属于可控增量。
+
+---
+
+## 5. 对时序训练的潜在收益
+
+1. **增强短时动态覆盖**：补帧后，模型更容易观察目标运动、交互关系变化与过渡状态。  
+2. **降低信息断裂**：关键帧之间不再“跳变过大”，有利于时序模块（如时序注意力、时序卷积）稳定学习。  
+3. **控制成本**：固定每区间采样数使得数据规模增长近似线性，可用于大规模训练。
+

+## 6. 使用方式
+
+### 6.1 默认策略（推荐）
+
+```bash
+bash prepare_actiongenome_frames.sh
+```
+
+默认行为：
+
+- `KEEP_ALL_FRAMES=0`
+- `EXTRA_FRAMES_PER_INTERVAL=2`
+
+即：关键帧 + 每相邻关键帧区间补 2 帧。
+
+### 6.2 仅关键帧（回退）
+
+```bash
+EXTRA_FRAMES_PER_INTERVAL=0 bash prepare_actiongenome_frames.sh
+```
+
+### 6.3 全帧
+
+```bash
+KEEP_ALL_FRAMES=1 bash prepare_actiongenome_frames.sh
+```

+## 7. 实验建议（论文可复现）
+
+建议最少进行三组对照：
+
+- **A**: annotation-only（`EXTRA_FRAMES_PER_INTERVAL=0`）
+- **B**: 本文策略（`EXTRA_FRAMES_PER_INTERVAL=2`）
+- **C**: full-frames（`KEEP_ALL_FRAMES=1`）
+
+对比指标建议包含：
+
+- 关系检测主指标（如 Recall@K / mR@K）
+- 训练吞吐（samples/s）
+- 显存峰值与磁盘占用
+- 收敛轮次与验证集稳定性（方差）
+

+
+## 8. 局限性与后续方向
+
+1. 该策略为**固定密度**采样，尚未根据动作速度自适应调整。  
+2. 对长区间仅采 2 帧可能仍不足，可考虑按区间长度动态设置 \(m\)。  
+3. 可进一步引入基于光流/运动幅度的内容感知抽帧，提高帧利用效率。
